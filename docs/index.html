YOLO26 Real-Time Object Detection

Webcam object detection with Ultralytics YOLO26, PyTorch and OpenCV. Detects the 80 COCO classes, draws labelled boxes with an FPS overlay and prints a debounced list of what is in view.

View on GitHub Installation YOLO26 docs

Features

Five model sizes

Choose from yolo26n, s, m, l or x with a single --model flag.

Smart device selection

Uses CUDA when PyTorch can really run on the GPU, otherwise falls back to CPU. FP16 on GPU.

Class filtering

Keep only the classes you care about, by name or COCO id.

Stable output

Per-frame detections are debounced so one-frame flickers are not reported.

Robust camera I/O

DirectShow on Windows, MJPG for HD at 30 FPS, clean shutdown on read failures.

Typed, modular code

Separate detection, drawing and CLI layers with explicit type hints.

Quick start

git clone https://github.com/evez12/Object-detection.git
cd Object-detection
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

python main.py --model yolo26n.pt --conf 0.4

Press q in the video window to quit. Weights are downloaded automatically on first run.

Choosing a model

Informal one-frame test on an RTX 5070 Laptop GPU (a computer mouse held in a hand). Not a benchmark.

Modelms / frameResult for the mouse
yolo26n21"cell phone" 0.74 (wrong)
yolo26s19"cell phone" 0.61, "mouse" 0.26
yolo26m26not detected
yolo26l38"mouse" 0.62
yolo26x39"mouse" 0.53

With yolo26l and a 1280x720 webcam, the full loop runs at about 26 FPS.

Why no live in-browser demo?

This is a desktop application: it reads a local webcam through OpenCV and runs PyTorch inference on your machine. GitHub Pages only hosts static files, so this page documents the project and links to the source.
